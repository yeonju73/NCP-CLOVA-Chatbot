# NCP-CLOVA-Chatbot
우리FISA NCP CLOVA Chatbot 프로젝트입니다.

## 우리FISA 상담 챗봇

우리FISA 아카데미 수강생을 위한 웹 기반 상담 챗봇입니다.
사용자는 자연스럽게 질문을 입력하고, 챗봇의 응답을 실시간으로 확인할 수 있습니다.

### 프로젝트 개요
- 주요 목적: 챗봇 기반 상담 UI 제공
- 실제 서비스와 유사한 채팅 UX 구현
- 대상 사용자: 우리FISA 아카데미 수강생

### 주요 화면 구성
- 채팅 메시지 영역
- 사용자 입력 영역
- 다크모드 토글
- 스크롤 하단 이동 버튼
- 대화 초기화 모달

### 주요 기능

#### 1. 채팅 UI
- 사용자 / 챗봇 말풍선 분리
- 메시지 추가 시 자동 스크롤
- 엔터 키 전송

#### 2. 챗봇 응답 대기 표시
- 챗봇 응답 중 Typing Indicator(점 애니메이션) 표시
- 응답 도착 시 자동 제거

#### 3. 중복 전송 방지
- 응답 대기 중:
- 입력창 비활성화
- 전송 버튼 비활성화
- 중복 요청 방지 로직 적용

#### 4. 다크 모드 지원
- 해/달 토글 버튼으로 테마 전환
- CSS 변수 기반 색상 관리
- 모든 UI 요소에 테마 일관성 유지

#### 5. 메시지 복사 기능
- 챗봇 메시지 우측 하단 복사 버튼 제공
- 클립보드 복사 기능 구현

#### 6. 스크롤 UX 개선
- 채팅이 많아질 경우:
- 하단 이동 플로팅 버튼 표시
- 스크롤이 하단일 경우 버튼 자동 숨김

#### 7. 대화 초기화 기능
- 대화 초기화 시 모달 확인
- 초기 안내 메시지로 상태 복원

#### 8. 질문/답변 구성, 서버

- NCP Colva Chatbot에 우리FISA의 기본적인 정보들 미리 입력 후 빌드
- 프론트엔드에서 전달받은 사용자 질문을 Express 서버가 수신
- NCP CLOVA Chatbot Invoke API에 맞는 요청 payload 생성
- 요청 본문 기반으로 HMAC-SHA256 Signature 생성 후 헤더에 포함
- NCP로 요청을 전송하고 응답을 수신
- 수신한 응답을 프론트로 반환하여 채팅 UI에 출력
